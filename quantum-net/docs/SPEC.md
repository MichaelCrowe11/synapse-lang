# QNet Language Specification

Status (2026-09-10): this is a specification target. What executes today is
flat network grammar validation (`synapse-qnet`, reported as `parse-only`) and
the scheduler, fiber and entanglement-attempt primitives in `qnet_runtime`.
Protocol sections below (QKD, teleportation, swapping, purification) are roadmap
and carry no security or fidelity claim.

This document outlines the specification for the Quantum-Net (QNet) language.
